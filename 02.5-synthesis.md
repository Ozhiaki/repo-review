# The Synthesis
*An optional interstitial prompt for composing The First Read and The Discounted Artifact before deeper passes*

---

## Why this is a separate document

The Discounted Artifact already revises the First Read. It names what the first
pass under-read, rewrites the affected sections, and records the delta. That is
the analytical correction.

Sometimes a human curator needs one more artifact before moving on to Trace,
Twin, or Lift: a compact synthesis of what the first two passes now jointly say.
This pass exists for that reading step. It lets pass 2 leaven pass 1, preserving
the movement between them while producing one current account of the repo's
shape.

This is not a new repo inspection pass. It should not hunt for new evidence,
rerun First Read, or redo Discounted Artifact. It composes the already-produced
outputs so the next human or downstream pass can carry a clearer current
judgment.

---

## How to use this document

Paste this prompt after The Discounted Artifact is complete and before The Trace
if you want a compact current account for your own reading or for downstream
handoff.

Provide the analyzer with:

- The First Read output, prose and YAML appendix.
- The Discounted Artifact output, prose and YAML appendix.
- The repo identifier and source state if either prior appendix is missing it.

If conversation context has been lost, start a new chat with the two prior
outputs attached and paste this pass as the first message.

---

## The Prompt

You have produced two repo-review outputs:

1. The First Read.
2. The Discounted Artifact.

Produce a synthesis of those first two passes, allowing pass 2 to leaven the
understanding compiled in pass 1.

You are not rerunning either pass. You are not performing The Trace. You are not
searching for a twin. You are not looking for extractables. Use the two prior
outputs as the evidence base. Inspect the repo again only if a prior output is
ambiguous in a way that prevents an honest synthesis, and name that inspection
plainly if you do it.

### 1. Establish the inputs

Name the two prior artifacts and whether each has prose and structured YAML.
Extract the focal repo source state from the appendices when available. If both
source states agree, use that value in the synthesis. If they differ, explain
the mismatch and use the most precise state actually synthesized.

### 2. Compose the current understanding

Write one current account of the repo after the discounted artifact correction.
Focus on:

- What the First Read got right.
- What the Discounted Artifact sharpened, softened, redirected, or refuted.
- Which central abstraction now best names the repo.
- Which taste verdict now survives.
- Which uncertainty matters most before Trace.

Do not smooth away the delta. The movement from pass 1 to pass 2 is part of the
finding.

### 3. Keep the scope narrow

This synthesis should be useful to a human reader preparing for Trace. It should
not pre-answer Trace by making claims about runtime enforcement unless the first
two passes already established them.

---

### Output Format

Produce two outputs:

**Part A: Prose Output**

Use this structure:

**A. Inputs**
Name the two prior passes consumed and any source-state caveat.

**B. Current Thesis**
One or two paragraphs stating the current best account of the repo after pass 2.

**C. What Pass 2 Leavened**
Name the important movement from pass 1 to pass 2: correction, sharpening,
softening, redirection, or refutation.

**D. Current Verdict**
State the synthesized central abstraction, taste verdict, signature move, and
weakest remaining uncertainty.

**E. What Trace Should Test**
Name the smallest load-bearing obligation or enforcement question Trace should
consider first.

**Part B: Structured Appendix**

After the prose, append a YAML block in this exact shape:

Use `source_state` to identify the focal repo source state synthesized. If the
prior source states disagree or are missing, use the best available value and
explain the precision in `source_state_notes`.

---

### A note on tone

Write this as a concise current judgment, not a victory lap for either prior
pass. If pass 1 was lucky, say it was lucky. If pass 2 overcorrected, say that.
If the strongest synthesis is that the two passes point at the same underlying
idea from different directions, name both directions.

The discipline is to leave the next reader with the shortest honest account of
what the review now believes before enforcement is tested.
